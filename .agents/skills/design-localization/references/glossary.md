# 集中术语表

本文件是本 skill 唯一的专有术语维护位置。表中的英文、日文是项目默认译法，可按用户决策在这里修改；它们不是卡名数据库，也不声称所有自定义机制都有官方译法。调整后检索目标语言对应用法，按实际范围同步文本，禁止不分上下文全局替换。

## YGO 与项目机制

| 中文与别名 | eng | jpn | 语义与使用限制 |
| --- | --- | --- | --- |
| 召唤 | Summon | 召喚 | 本项目通用召唤；不能擅自加实体卡每回合通常召唤次数限制。 |
| 通常召唤 | Normal Summon | 通常召喚 | 仅在源文明确区分通常召唤时使用。 |
| 特召、特殊召唤 | Special Summon | 特殊召喚 | 中文简称与全称统一译法；手牌满足特召条件可免费打出，按具体源文描述。 |
| 送墓 | Sent to the GY | 墓地へ送られた時 | 本项目关键词的触发点是怪兽死亡；动词叙述可写 send to the GY / 墓地へ送る，不能扩大为任意弃牌触发。 |
| 除外 | Banish | 除外 | 本项目削减等量最大/当前生命，可致死；不是 Exhaust，也不是把卡移出游戏。说明保持中文机制。 |
| 融合召唤 | Fusion Summon | 融合召喚 | 不省略素材要求。 |
| 连接召唤 | Link Summon | リンク召喚 | 连接数使用 Link / リンク；不混同等级。 |

| 同调召唤 | Synchro Summon | シンクロ召喚 | 保留等级合计要求。 |
| 接触融合 | Contact Fusion | コンタクト融合 | 按项目悬浮提示解释直接融合。 |
| 融合素材 | Fusion Material | 融合素材 | 随句式使用复数。 |
| 连接素材 | Link Material | リンク素材 | 同上。 |
| 超量素材 | Xyz Material | エクシーズ素材 | 不混作普通弃牌。 |

| 装备 | Equip | 装備 | 说明中的离场和弃牌堆去向保留。 |
| 强化 | Boost | 強化 | 本项目攻击力/生命增量，非 STS2 升级。 |

## 原版 STS2 用词与牌堆

原版名词优先按当前游戏同一 key 的 eng/jpn 文件核实，再在这里调整约定。以下原版关键词于 2026-09-04 从本地原版 `card_keywords.json` 核对；牌堆及普通 UI 项为项目默认用语，实际工作遇到冲突时以当前原版显示为准。

| 中文与别名 | eng | jpn | 说明 |
| --- | --- | --- | --- |
| 消耗 | Exhaust | 廃棄 | 原版消耗，不与“除外”混用；“消耗能量/层数”是普通动词，不套本行。 |
| 保留 | Retain | 保留 | 原版关键词。 |
| 升级 | Upgrade | アップグレード | 不与本项目“强化”混用。 |
| 手牌、手卡 | Hand | 手札 | 按句式调整大小写。 |
| 抽牌堆 | Draw Pile | 山札 | 不改成实体卡 Deck 的区域规则。 |
| 弃牌堆 | Discard Pile | 捨て札 | 不自动改成 GY / 墓地。 |
| 消耗堆 | Exhaust Pile | 廃棄札 | 不自动改成 Banished cards。 |
| 牌组、卡组 | Deck | デッキ | 区别携带卡组与战斗抽牌堆。 |

力量、敏捷、易伤、虚弱、格挡等按原版当前本地化同 key 查证，不凭 YGO 词汇替代。系列名、人物名和卡名不做词根级替换；必要时查证各自官方名称，避免把「电子龙」卡名直接用于所有「电子」系列。
