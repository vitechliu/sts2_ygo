泛用卡池必须依据每行的 `卡池` 字段选择实际代码池，例如 `FusionCardPool`、`CommonCardPool`、`MachineCardPool` 或 `LinkCardPool`；不得仅凭工作表名称统一映射。

## 状态与优先级

当前任务优先级使用 `P0`、`P1`、`P2`、`P3`。常见任务状态包括 `待开发`、`开发中`、`已完成`、`长期任务`；卡牌常见状态包括 `待设计`、`待开发`、`待测试`、`已完成`。

读取时接受文档中的现有值。写入时优先复用现有状态，不自行创造 `阻塞` 等新状态；阻塞信息写入 `AI自动化进度/备注`。

## 回写规则

- 以精确任务名或卡名重新定位行；写入前后都回读。
- `卡片id` 非空时不覆盖，除非用户明确要求纠正且仓库/导入结果能唯一证明。
- 卡牌只有在 `$design-cards` 所需代码、本地化与构建验证成功后才写为 `待测试`。
- 需要游戏内验证时，在自动化备注中明确说明，但不把未完成的关键代码验证包装成完成。
- 备注保持短小、可执行，不粘贴命令日志。
- 三次及以上写入遵守 `$tencent-docs` 的批量接口要求。
