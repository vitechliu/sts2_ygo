# 连接召唤优化与复现

保留现有门环、八方向连接标记、光轨和正式召唤结算，修正素材空间姿态，补齐命中长芒与结果蓝白爆发。源工程保持只读。

## 坐标与混合

使用 `H=diag(1,1,-1)`，位置 `Hp`、旋转 `HRH`，四元数 `(-x,-y,z,w)`。Unity ZXY 对应 `Ry·Rx·Rz`，Godot 为 YXZ 顺序及 `(-x,-y,z)`。轨道偏移、Clip 偏移、曲线和父节点按矩阵组合。双素材轨道的 `m_InfiniteClipOffsetEulerAngles.z` 为 335° / 25°，不能省略。

源卡面在 XZ 平面；转换后实时卡面 Quad 的右为 -X、上为 +Z、法线为 +Y。捕获真实卡面并保留宽高比和对称透明边距，只隐藏此次克隆的 `CardContainer/Shadow`。网格导入翻转 Z、UV 的 V 及三角形绕序。

源 `C_ParticleAdd` 使用 `Blend SrcAlpha One`、关闭深度写入；白色长芒与红色柔边共用空间位置。透明舞台按预乘 Alpha 合成。完整审计含 20 个 Prefab、24 个材质、92 个依赖；12 个材质 shader 缺失或为占位。光轨和动态卡面轮廓属于重建，不能称为源 shader 完整移植。

## 正式测试指令

在单机测试存档、玩家行动阶段使用。测试需要一个手牌空位，单素材需要一个随从空位，凯旋样例需要两个。指令在同步 `ConsoleCmdGameAction` 与 `GameActionPlayerChoiceContext` 中准备真实卡牌，经正式连接素材校验、消费和结果卡打出，不直接生成结果怪兽。开始后自动关闭控制台。

| 指令 | 验证内容 |
| --- | --- |
| `vtest link-single` | 比特机灵作为合法普通怪兽素材，召唤连接蜘蛛；只有下箭头 |
| `vtest link-sieger` | 电子龙、原始电子龙作为合法机械族素材，召唤电子龙·凯旋；左、下箭头 |
| `vtest link-sieger-slow` | 同凯旋样例，仅将源 1.25–1.3333 秒素材退出段放慢十倍，用于检查轨迹 |
| `vtest link-sieger-upgraded` | 升级两张素材及结果卡，核对实时卡面和升级后属性 |
| `vtest link-minimal` | 临时使用快速动画执行同一凯旋样例 |
| `vtest link-none` | 临时使用无动画执行同一凯旋样例 |
| `vtest link-prepare` | 只准备凯旋及两只场上素材，随后从额外卡组手动点击凯旋并选择素材；遵循原动画设置 |

自动样例通过正式选择规格校验指定素材，不弹手动选择界面。`link-prepare` 用于另行验证选择界面及 managed net action。临时动画模式结束后恢复，诊断不修改全局时间和持久设置。原有 `xyz-*`、`ritual-*` 指令保留。

## 实现边界

源素材展示已逐层转换 1–8 张卡的父变换、无限轨道偏移和位置/欧拉角曲线；当前源这些轨道的起点和 ClipIn 均为 0、速度均为 1。实时卡面纹理与源卡图形状不同，尺寸按实际捕获比例适配。

门环和轨迹网格沿用现有资源。箭头白芒使用源 `flare007` 纹理重建为八束宽窄交错、短时错峰的叠加光，按各连接标记的实际位置和方向锚定；源随机粒子参数已保留在审计中，但不声称随机发射与 Unity 完全一致。门中心仅增强源纹理亮部；结果爆发使用当前结果卡的真实透明轮廓，避免固定卡图。透明视口使用黑色零 Alpha 背景，避免 HDR Glow 将白色零 Alpha 背景合成为白底。

正式 Link 2 主演出约 5.3 秒，另有正式素材离场、卡面捕获和随从生成耗时。录像必须标注真实 PTS、发布版本和用途；局部慢放只验证姿态，不能证明正常速度节奏。三至八素材、联机和其他屏幕比例需独立实机验收。
