# 仪式召唤开发与复现

仪式怪兽来自手牌；「混沌的仪式」选择手牌中的「混沌战士」，解放手牌或场上等级合计**恰好 8 星**的怪兽。目标自身不能作为素材，场上素材可以释放随从位置。素材统一进入弃牌，目标经原有自动打牌与随从来源卡生命周期进入场上牌堆，不进入额外牌堆，也不挂载素材。

正式入口是 `RitualSummonCmd.Execute`，素材选择使用 `SummonMaterialSelectCmd` 和调用方的 `PlayerChoiceContext`。演出独立于玩法结算；完整模式展示源时序，快速模式保留素材退场和蓝色结果卡，无动画及远端仍执行结算。目标重复执行由作用域保护，演出和卡面捕获在 `finally` 中释放。

## 可重复测试

发布后重启游戏，沿用测试存档，进入单机 YGO 角色战斗，等待玩家行动阶段，关闭选卡等弹窗。测试需要一个空随从位；单素材需要两个手牌空位，其他指令需要三个。控制台执行后自动关闭。

| 指令 | 验证内容 |
| --- | --- |
| `vtest ritual-single` | 手牌 8 星混沌战士作为单素材，完整仪式召唤另一张混沌战士 |
| `vtest ritual-dual` | 场上 5 星电子龙和手牌 3 星原始电子龙，完整仪式召唤 |
| `vtest ritual-dual-slow` | 同双素材，只将源时间 1.25–1.333334 秒的退出阶段放慢十倍 |
| `vtest ritual-minimal` | 同双素材，以快速模式完整结算 |
| `vtest ritual-none` | 同双素材，以无动画模式完整结算 |
| `vtest ritual-prepare` | 准备目标、合法素材和仪式魔法，随后手动打出魔法并选择素材 |

自动测试通过 `ConsoleCmdGameAction` 执行，预选真实素材后仍使用正式规则重建、校验、消费和召唤。它不直接生成最终怪兽。模式覆盖仅作用于本次异步调用链；`ritual-prepare` 结束后，手动打出的魔法服从玩家持久设置。原有 `xyz-infinity` 指令保留。

未升级结果为 12 攻 / 10 生命；升级后 15 攻 / 13 生命。魔法消耗 1 能量，升级后 0 能量。手动测试除核对素材去向外，还应核对魔法进入弃牌、目标离开手牌、无残影以及后续操作可继续。控制台“演出调用完成”不等于视觉验收。

## 源结构与转换

```powershell
python tools/import_ritual_presentation.py --source <MDPro3工程>/Assets --output VYgo/scenes/summon/ritual
dotnet publish VYgo.csproj -c ExportRelease -f net9.0 -o ./bin/ExportRelease/net9.0/publish
```

导入脚本只读源工程，输出禁止位于源目录内。导出主体与 1–6 素材共 7 组、24 个材质及 81 个带 SHA256 的依赖；解析嵌套 Prefab 覆盖、父层级、Timeline 激活、轨道偏移、Clip 偏移、动画曲线及粒子模块。实际源资源包含 27 个导出纹理／网格。重复导入应比较 JSON 和资产字节，不能只验证脚本退出码。

坐标转换为 `H=diag(1,1,-1)`，`p'=Hp`、`R'=HRH`，四元数为 `(-x,-y,z,w)`。Unity ZXY 对应矩阵 `Ry·Rx·Rz`；Godot 使用 YXZ 顺序及 `(-x,-y,z)`。轨道与 Clip 偏移按矩阵组合，再叠加父层级。源卡面为 XZ 平面，右为 -X、上为 +Z、正面为 +Y；实时卡面 Quad 使用相应基向量，保留真实捕获宽高比及对称边距。网格翻 Z、UV 翻 V、三角形反绕序。

卡面与轮廓在同一透视空间。只隐藏仪式捕获克隆的 Shadow；正常卡牌不受影响。源工程为 Gamma 色彩空间，仪式加色粒子先在 Gamma 中应用透明度，再转为 Godot 的线性能量。透明舞台采用预乘 Alpha 合成，黑色纹理区域不写成矩形遮挡。

| 源时间（秒） | 阶段 |
| --- | --- |
| 0–0.1667 | 暗幕与素材出现 |
| 0–1.25 | 素材微转；双素材右卡从 0.5 秒开始 |
| 1.25–1.3333 | 素材快速向上飞出；不以缩小淡出代替 |
| 1.3333 / 1.7167 | 两批法阵层开始 |
| 1.8333–2.3 | 八处火焰每 0.0667 秒依次出现 |
| 2.3833–3.7667 | 与素材数量对应的光轨汇入 |
| 3.35–3.5833 | 中心法阵增亮 |
| 3.8667–4.7 | 结果卡翻入并接近镜头 |
| 4.7–5.2 | 结果叠光与源金色环纹扩张、淡出 |
| 4.7333–5.0333 | 粉紫爆发 |
| 5.7167–5.8833 | 暗幕和舞台退出 |

源 `Cylinder`、`Reflection` 轨道被静音且节点初始禁用，保持禁用。金环来自仪式本身的 `tmm_Square01`，不是超量效果。源火焰局部 X 经节点 Z=90° 旋转后向上，UV.x 从根部延伸到顶部。

## 还原边界

11 个材质引用缺失或占位 shader，其中包括不使用的占位卡材质。火焰、光轨及动态卡面的增亮算法属于重建，不能称为源 shader 完整移植。噪声柱虽有源依赖，但其源轨道已禁用。法阵和爆发分别使用 1.5 / 1.6 的局部强度补偿，这是实机对照后的观感校正，并非源材质原值。完整演出最多展示源提供的前六张素材；规则仍消费全部合法素材。

参考视频应按真实 PTS 提取；视频裁切起点不等于 Timeline 零点。短动作必须检查连续帧及其间隔，慢放只能诊断姿态与方向。每次资源修改后均需发布、确认游戏目录 DLL/PCK 更新并重启。旧构建、黑屏采集和慢放证据应独立标注，不可当作最终正常速度验收。
