# 怪兽光环视觉预览

该独立 Godot 演示与正式怪兽共用光环资源。演示中的行动状态由按钮模拟，不依赖战斗、卡牌或头顶图标。

在项目根目录运行：

```powershell
.\tools\preview-monster-aura.ps1
```

入口读取本机 `env.props` 的 `GodotPath`，构建后打开 1120×720 窗口。Godot 编辑器中也可以打开 `monster_aura_demo.tscn`，按 F6 运行当前场景。

窗口每 5 秒切换一个阶段，30 秒循环：淡灰常态 → 召唤从中心放大 → 淡绿可行动 → 行动成功后渐暗 → 恢复亮色 → 死亡先淡后缩。点击阶段按钮切换为手动模式，点击自动按钮恢复循环；底部可调亮色与过渡时长，并切换悬停律动。过渡时长表示接近目标颜色和亮度的时间（约 95%），不会瞬间切换。

演示不录屏，也不自动截图。

可复用资源是 `res://VYgo/scenes/vfx/monster_aura.tscn`，由 `NMonsterAura` 管理独立材质、颜色、旋转、发光和状态过渡。暴露 `AuraWidth`（基准横向直径）、`SizeMultiplier`（默认1.1，即整体放大10%）、`RestColor`、`ActiveColor`、`TransitionSeconds`、`HoverAmplitude`（默认±3.5%）和 `HoverPeriodSeconds`（默认1.4秒）。三个示例基准宽度为128、192、288，椭圆比例固定4:1，仅整体等比缩放。外侧柔光略超出主环直径。

光环由纯程序化 shader 绘制，不使用图片或纹理压缩。线条通过屏幕导数 `fwidth` 做像素覆盖抗锯齿；主环几何半宽0.014（原半高宽约0.0103），最小显示宽度约1.1像素。刻线同样过滤边缘，并在主环短轴从30像素缩至14像素时逐渐淡出，以减少缩小后的闪烁和噪点。柔光强度与行动亮暗参数保持原值。

正式接入由 `NMonsterVisuals` 统一挂载，以 `%Bounds`（Control）的 `Size.X` 为局部宽度，继承怪兽视觉节点的缩放；脚底位置取 Bounds 底边中心并转换到身体局部坐标，不读取原图分辨率。悬停复用 MinionLib 交互所依赖的 `NCreature.Hitbox` / `IsFocused`，不增加热区。生命周期缩放在根节点、悬停正弦律动在绘制子节点，二者不会竞争属性。

行动亮暗由 `BasePerTurnMonsterAction` 的剩余次数、CanAct、队列占用和合法目标生成，与头顶图标资源无关。死亡事件发生时光环保持世界变换，临时转挂战斗场景，先淡后缩后自行释放，避免怪兽节点提前销毁打断动画；不延迟或改变死亡结算。战斗场景销毁时也会回收剩余光环。
