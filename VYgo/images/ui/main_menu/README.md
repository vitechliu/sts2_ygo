# VYgo 主菜单资源

将主菜单美术放在本目录；资源不存在时，代码会保留原版背景或使用占位图标。

- `background.png`：全屏背景，推荐源图尺寸为 3440×1440。
- `decoration_back.png`：可选的后层全屏装饰。
- `decoration_front.png`：可选的前层全屏装饰。
- `icons/profile.png`：存档按钮图标。
- `icons/patch_notes.png`：更新记录按钮图标。
- `icons/settings.png`：设置按钮图标。
- `icons/quit.png`：退出按钮图标。

背景和装饰使用保持比例覆盖模式。构图时应为左侧菜单、右上工具栏与右下日志预留安全区。
